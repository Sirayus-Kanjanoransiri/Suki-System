## ระบบบริหารจัดการร้านอาหาร (Restaurant Management System)
ระบบบริหารจัดการร้านอาหารแบบครบวงจร พัฒนาขึ้นเพื่อช่วยเพิ่มประสิทธิภาพในการดำเนินงานของร้านอาหาร ตั้งแต่การรับออเดอร์ การจัดการโต๊ะ การคำนวณค่าใช้จ่าย ไปจนถึงการสรุปยอดขายและการจัดการวัตถุดิบในคลังสินค้า ช่วยลดความผิดพลาดในการทำงานและยกระดับการบริการให้รวดเร็วยิ่งขึ้น
## คุณสมบัติหลักของระบบ (Features)## 1. ระบบจัดการโต๊ะอาหารและการจอง (Table & Reservation Management)

* ตรวจสอบสถานะโต๊ะอาหารแบบเรียลไทม์ (โต๊ะว่าง, กำลังรับประทาน, รอทำความสะอาด)
* บันทึกข้อมูลการจองโต๊ะล่วงหน้าพร้อมระบบแจ้งเตือน

## 2. ระบบจัดการเมนูอาหารและคำสั่งซื้อ (Menu & Order Management)

* จัดการรายการอาหาร หมวดหมู่ ราคา และตัวเลือกเพิ่มเติม (เช่น ระดับความเผ็ด, เพิ่มท็อปปิ้ง)
* รับออเดอร์จากลูกค้าและส่งตรงไปยังห้องครัวหรือบาร์เครื่องดื่มโดยอัตโนมัติ

## 3. ระบบคิดเงินและออกใบเสร็จ (Billing & POS System)

* คำนวณค่าอาหาร ภาษีมูลค่าเพิ่ม (VAT) และค่าบริการ (Service Charge) อัตโนมัติ
* รองรับการชำระเงินหลายรูปแบบ เช่น เงินสด, บัตรเครดิต และ QR Code พร้อมระบบแยกบิล

## 4. ระบบบริหารคลังวัตถุดิบ (Inventory Management)

* ตัดยอดวัตถุดิบในคลังสินค้าทันทีเมื่อมีการขายอาหาร
* ระบบแจ้งเตือนเมื่อวัตถุดิบใกล้หมดหรือต่ำกว่าเกณฑ์ที่กำหนด

## 5. ระบบรายงานและวิเคราะห์ผลการดำเนินงาน (Reporting & Analytics)

* สรุปยอดขายรายวัน รายสัปดาห์ และรายเดือน
* วิเคราะห์เมนูอาหารที่ขายดีที่สุดเพื่อนำไปวางแผนการตลาด

## ขั้นตอนการติดตั้ง

   1. จำลองซอร์สโค้ดจากคลังจัดเก็บ (Clone the repository)

git clone https://github.com
cd restaurant-management-system


   1. การตั้งค่าระบบหลังบ้าน (Backend Setup)

cd backend
npm install          # หรือ pip install -r requirements.txt
cp .env.example .env # ตั้งค่า Environment Variables ของคุณในไฟล์ .env
npm start            # หรือคำสั่งเริ่มทำงานของภาษาที่ใช้


   1. การตั้งค่าระบบหน้าบ้าน (Frontend Setup)

cd ../frontend
npm install
npm run dev


   1. เปิดใช้งานระบบผ่านเบราว์เซอร์ที่โปรโตคอล http://localhost:3000
